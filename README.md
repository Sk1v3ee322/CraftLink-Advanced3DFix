# CraftLink Advanced 3D Fix

**A community-built Dynamic Link prototype for Artcraft.**

## Features

- Transfer selected timeline clips from FilmCraft to EffectCraft.
- Replace selected clips with linked compositions.
- Automatically render updated compositions.
- Synchronize rendered results back into FilmCraft.
- ProRes 4444 support for alpha channel preservation.
- Advanced 3D Layer Styles rendering fixes.

## Tools

- **CraftLink Installer** — automated installation.
- **CraftLink Patcher** — source-level patching.
- **CraftLink Source** — implementation patches and documentation.

## Compatibility

- FilmCraft 0.20.1
- EffectCraft 0.24.1
